# 輪講ノート

Node.js 24 で `npm ci`、`npm run dev` を実行し、表示された localhost の URL を開きます。

資料一覧で開いた PDF とページごとの付箋はブラウザーの IndexedDB に保存します。同じ PDF は内容のハッシュで識別します。最後に開いた資料とページを次回復元します。保存先はブラウザーとオリジンごとに独立しています。

## 2端末で資料を共有する

1. 2端末を同じ信頼できるネットワークにつなぎます。サーバーを動かすPCで `npm run build`、`npm run preview -- --host 0.0.0.0` を実行します。
2. 発表者は Vite が `Network` に表示した LAN アドレス（例 `http://192.168.1.10:4173`）でアプリを開き、PDFを開いて「会を作成」を押します。共有できるPDFは64 MBまでです。
3. 参加者は「参加URL」を別端末で開きます。発表者が「次へ」で3ページ目に進むと、参加者にも通常1秒程度で3ページ目が表示されます。参加者のブラウザーを再読み込みしても3ページ目から表示されます。
4. どちらかの端末で3ページ目に付箋を保存します。もう片方にも同じ付箋が表示され、両端末で再読み込みしても残ります。

会のPDF、ページ切替履歴（ページ番号・サーバーのUTC時刻）、会で保存した付箋は `.rooms/rooms.sqlite` に保存されます。参加URLを知っている端末は、サーバー稼働中にその会のPDFを閲覧し、ページごとの付箋を読み書きできます。発表者の操作権限は会を作ったブラウザーのタブにあり、そのタブを再読み込みしても復元されます。

会の付箋は1件4000文字までです。通信が途切れた場合は、送信待ちの付箋がブラウザーに残ります。同じ会を開いていると、接続の回復後に自動で再送されます。
